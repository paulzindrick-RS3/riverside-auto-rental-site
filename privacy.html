Privacy

What this website collects, and how to ask a privacy question.

Riverside Auto Rental is at N5856 WI-54, Black River Falls, WI 54615. This page describes the contact form on this website and, once it is turned on, Riverside Rental Help. Until that automated assistant is turned on, this website does not send chat messages to OpenAI.

This website uses Google Analytics to understand how visitors use the site.

Contact form

The contact page has a form that opens the email program on your device, addressed to contact@riversideautorental.com. The fields are your name, email address, phone number, a topic, and a message. This website does not store that form on a server.

Reaching a person

When Riverside Rental Help is turned on, a visitor who wants a person can text or call 715-396-1466. That text or call goes to the business directly, not through this website.

Chat messages

When Riverside Rental Help is turned on, the question you type is sent to OpenAI so it can write a reply from the pages published on this website. The question is sent with up to the eight most recent messages already in that conversation. Before the reply is written, the question is also sent to OpenAI for a moderation check. Numbers that look like a payment card or a Social Security number are removed first.

This website's code does not set how long OpenAI keeps those requests. The key used to call OpenAI stays in the site's hosting settings. It is not placed in the page you see.

While the chat window is open, the conversation stays in the browser for that visit. A session id is stored in the browser's session storage and is removed when you close the tab. The chat code does not set a cookie for that id.

Each chat request writes a short status line, such as whether a limit was hit or which model answered. That line does not include your message. The host may still record the time of the request and a status in its own logs. How long those logs are kept is not set in this website's code.

The chat function also stores counters so it can limit how many messages are sent and the daily cost of answers. A counter is a count and a time, or a daily total. It is tied to a shortened hash of the network address or the session id, not to your name. The counters do not include the text of your messages. The code does not delete old counters.

Sensitive numbers

Don't type a driver's license number, a payment card number, a Social Security number, or other sensitive numbers into the chat or into the contact form. The chat function removes a number that looks like a payment card or a Social Security number before it is sent on. Don't rely on that to catch every number.

Privacy questions

For a privacy question, call or text 715-396-1466 or email contact@riversideautorental.com. This website does not keep a copy of the chat, and it does not have a button that deletes a question sent to OpenAI.
